Great. Now test the project in small steps, not all at once.

Step 1: Activate Virtual Environment

Windows PowerShell:

cd power-window-agents

.\venv\Scripts\activate


or

venv\Scripts\activate


You should see:

(venv) PS C:\...

Step 2: Install Dependencies
pip install -r requirements.txt


If Streamlit wasn't already added:

pip install streamlit


For SQLite you need nothing extra because:

import sqlite3


is built into Python.

Step 3: Verify Environment Variables

Run:

Get-Content .env


Expected:

GEMINI_API_KEY=xxxxx

CHROMA_DB_DIR=data/kb


Notice:

Your agents use:

os.getenv("GEMINI_API_KEY")


not OpenAI.

So if you only have:

OPENAI_API_KEY=


the application will fail.

You need:

GEMINI_API_KEY=your_key_here

Step 4: Initialize Chroma

Run once.

python scripts/init_chroma.py


Expected:

ChromaDB 'standards' collection created successfully.

Step 5: Run Main Pipeline
python main.py


Expected flow:

Initializing SQLite database...

Generated XX requirements

Building Traceability Matrix...

Calculating Metrics...

PIPELINE SUMMARY

data/output/

If main.py Fails

Most likely causes:

Error 1
ModuleNotFoundError


Fix:

pip install -r requirements.txt

Error 2
GEMINI_API_KEY not set


Fix:

GEMINI_API_KEY=xxxxx

Error 3
Collection standards does not exist


Fix:

python scripts/init_chroma.py

Error 4
No module named src.validation


Fix:

Ensure folders include:

src/
 ├── validation/
 │    ├── __init__.py
 │    └── validator.py

 ├── persistence/
 │    ├── __init__.py
 │    └── sqlite_store.py

 ├── traceability/
 │    ├── __init__.py
 │    └── matrix.py

 ├── metrics/
 │    ├── __init__.py
 │    └── metrics.py


Those __init__.py files are important.

Recommended Execution Order

Every time:

1. activate venv

2. python main.py

3. streamlit run src/dashboard/app.py
